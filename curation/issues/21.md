# Upstream #21: [HIPE 2020 French] Entities split across sentence boundaries lead to invalid I-tag starts and fragmentede entity learning

Source: https://github.com/hipe-eval/HIPE-2022-data/issues/21
Upstream state: open
Snapshot: 2026-09-09

## Issue Summary
In the French HIPE 2020 corpus, sentence boundaries sometimes split annotated entities, causing the model to learn entity fragments instead of complete entities. This results in entities that incorrectly start with I-tags (Inside) after sentence boundaries, violating the BIO tagging scheme where entities should always start with B-tags (Begin).

## Problem Description
When an entity spans across a sentence boundary (indicated by `EndOfSentence` in the MISC column), the continuation of the entity in the next sentence starts with an I-tag instead of a new B-tag. This is problematic because:
1. The model learns incomplete entity patterns
2. Entities incorrectly begin with I-tags after sentence breaks

## Data
The attached CSV file reports all cases found in the French corpus (229 cases) with the following columns:
- **document_id**: Document identifier
- **number_of_splits**: Number of times the entity is split (count of `EndOfSentence` markers + 1 within the entity span)
- **tokens**: The tokens forming the entity
- **misc**: MISC column values (including `EndOfSentence` markers)
- **ner_coarse_lit**: BIO tags for NER coarse-grained annotation
[split_entities_details.csv](https://github.com/user-attachments/files/23631965/split_entities_details.csv)

## Examples
```
document_id: EXP-1798-02-15-a-i0004
Mlle. Eckard
Tokens: [Mlle, ., Eckard]
MISC: [NoSpaceAfter, EndOfSentence, ]
Tags: [B-pers, I-pers, I-pers]
→ "Eckard" starts a new sentence but continues with I-pers
```

```
document_id: EXP-1808-09-01-a-i0001
H.-F. JEAHJAQUET, greffier
Tokens: [H, ., -, F, ., JEAHJAQUET, ,, greffier]
MISC: [..., EndOfSentence, ...]
Tags: [B-pers, I-pers, I-pers, I-pers, I-pers, I-pers, ...]
→ Entity split across sentence boundary
```

## Impact
This annotation inconsistency affects model training by teaching the model that:
- Entities can legitimately start with I-tags
- Entity boundaries don't align with sentence boundaries
